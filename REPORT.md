1) Если приложение под root взломают — атакующий получит все права внутри контейнера. Под appuser прав мало, поэтому ущерб будет меньше. Даём только то, что нужно для работы.
---------------------------------------------------------
2) Redis без пароля. Откроем порт — любой сможет читать и менять данные. web и так видит его по имени внутри сети. Наружу — только то, что нужно пользователям (8080).
---------------------------------------------------------
3) Закрытый — как пароль, никому не показывать. Открытый — можно публиковать, по нему сервер проверяет, что у тебя есть закрытый. Отправлять можно только .pub
